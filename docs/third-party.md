# Third-party assets

## React Bits

Silk and Grainient source snapshots live in `src/vendor/react-bits/`. Sources: https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Backgrounds. Retrieved 2026-11-08. Source was formatted and the Next.js client directive removed for Vite. Context loss is deferred until the canvas is disconnected so Strict Mode effect replays do not blank the background. Their original rendering APIs remain intact.
